Cloud sync

Keeps this dashboard identical on your Mac and iPhone. Your figures are stored in a private repository that nobody can read without your token. Paste the same two values on both devices — after that it saves automatically and pulls the latest whenever you open it. Setup steps are in PHONE-SETUP.md in your fileDash folder.

Manual backup

Export writes everything — balances, activities, spends, ticked suggestions — to a JSON file. Keep it in your fileDash folder (in iCloud Drive if you want it on your phone). Import restores from a backup file and replaces what's currently here.
